# CS 499 — Computer Science Capstone

CS 499 is the final course in my Computer Science program. In it, I take work from earlier courses and enhance it in three areas of computer science: software design and engineering, algorithms and data structures, and databases. The finished ePortfolio will include a recorded code review, the original and enhanced versions of each artifact, a narrative explaining each enhancement, and a professional self-assessment, all presented on GitHub Pages by the end of the term.

## Planned Artifacts

These are the artifacts and enhancements I plan to complete over the term:

- **Software design and engineering:** Scalable, the Android weight-tracking app from [CS 360](../CS-360-Mobile-Architecture-and-Programming), restructured into the MVVM architecture with a repository layer, background database work, centralized input validation, and security hardening such as login throttling and session expiry.
- **Algorithms and data structures:** Scalable again, with its weigh-in history moved into indexed data structures and new trend analysis, including a sliding-window moving average and a projected goal date.
- **Databases:** The Grazioso Salvare dashboard from [CS 340](../CS-340-Client-Server-Development), rebuilt as a standalone application on a MongoDB server I set up myself, with schema validation, indexes designed around its queries, aggregation pipelines, and least-privilege database access.

As each enhancement is completed, I will add it here alongside the original version so the two can be compared.
