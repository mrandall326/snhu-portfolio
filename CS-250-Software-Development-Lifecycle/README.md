CS 250 – Software Development Lifecycle
Southern New Hampshire University

This folder contains my work for CS‑250: Software Development Lifecycle, a course focused on Agile methodologies, Scrum roles, 
iterative development, and professional communication within a software engineering team. The artifacts here demonstrate my ability
to participate in and facilitate Agile processes while contributing to the development of the SNHU Travel application.

📌 Course Overview
CS‑250 emphasizes:
  - Agile values and principles
  - Scrum roles and responsibilities
  - Sprint planning, execution, and review
  - Backlog refinement and user story creation
  - Test case development
  - Professional communication within a development team
  - Continuous improvement through retrospectives
The work in this directory reflects my role as both a Scrum Master and Product Owner during simulated team activities.

🧩 Key Artifacts
1. Scrum Master Journal
A written reflection on how I would plan and facilitate Scrum events, including:
  - Sprint Planning
  - Daily Scrum
  - Backlog Refinement
  - Sprint Review
  - Sprint Retrospective
This artifact demonstrates my understanding of team facilitation, communication, and Agile leadership.

2. Product Owner Journal
A reflection on prioritizing the product backlog, writing user stories, and ensuring stakeholder value. This artifact highlights my
ability to think strategically about customer needs and product direction.

3. Test Case Template
A structured test plan created for the SNHU Travel application. It includes:
  - Test case IDs
  - Preconditions
  - Step‑by‑step procedures
  - Expected results
This artifact demonstrates my ability to design clear, repeatable tests that support quality assurance.

4. Sprint Review & Retrospective Materials
Documentation showing how I evaluate team performance, identify improvements, and apply Agile principles to enhance future sprints.
