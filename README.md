# SNHU Bachelor of Science in Computer Science

## Coursework • Projects • Labs • Portfolio Artifacts
This repository is a collection of my work throughout the Bachelor of Science in Computer Science program at Southern New Hampshire University (SNHU). It serves as a central place to organize assignments, projects, diagrams, code samples, and documentation from each course as I move through the program. My goal is to build a clear record of my progress, show how my skills have developed over time, and create a portfolio I can continue to grow as I move toward a career in cybersecurity and software development.
## 🎓 Program Overview
The SNHU CS program covers a wide range of topics, from foundational programming and data structures to system analysis, software engineering, databases, and cybersecurity. Each course folder in this repository includes the major assignments, labs, and artifacts that demonstrate what I learned and how I applied those concepts.
