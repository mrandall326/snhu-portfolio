This repository contains my work for **CS 210: Programming Languages** at Southern New Hampshire University.

## 🛒 Corner Grocer Frequency Analyzer (Project Summary)
The Corner Grocer application reads a text file containing purchased items and generates:

- A **frequency count** of each item  
- A **search feature** to look up the count of a specific item  
- A **histogram** displaying item frequencies  
- A **backup data file** containing item counts  

The program uses:

- File I/O  
- Maps/dictionaries for frequency tracking  
- Input validation  
- Modular function design  
- A menu‑driven console interface  

For full technical details, see the project folder’s internal README.
