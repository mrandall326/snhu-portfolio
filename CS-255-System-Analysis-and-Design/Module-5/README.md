## 📄 Deliverable 2: Model Application Short Paper

This short paper explains how **process modeling** and **object modeling** apply to the DriverPass system.

### **Process Model Application**
- Describes how workflows such as scheduling, account management, and DMV updates move through the system  
- Highlights how process models clarify user responsibilities and data flow  
- Shows how sequential steps reveal bottlenecks and validation needs  

### **Object Model Application**
- Identifies key system entities (Customer, Driver, Car, Reservation, Package, Test, etc.)  
- Explains how attributes and relationships structure the system  
- Shows how object models support scalability, maintainability, and role‑based behavior  

### **Comparison**
- Process models = workflow clarity  
- Object models = structural clarity  
- Both together = complete understanding of system behavior and architecture
