# CS 255 – Module Seven Assignment  
### Presenting System Designs to Nontechnical Clients  
**Status:** Templates Uploaded — Final Deliverables Pending

This folder currently contains the **Module 7 templates** for *CS 255: Systems Analysis and Design*.  
Module Seven focuses on translating technical system designs into clear, accessible presentations for nontechnical stakeholders — a core skill for systems analysts.

The completed deliverables will be added once the assignment is finished.

---

## 📌 Module Overview
Module Seven emphasizes **communication**, specifically how to present:

- System requirements  
- UML diagrams  
- Security considerations  
- System limitations  
- Overall system design rationale  

…in a way that nontechnical clients can understand and confidently approve.

This module builds on all previous work (Modules 1–6 and Project One) and prepares you for the final stages of Project Two.
