# CS 255 – Module Two Assignment  
### Functional & Nonfunctional Requirements Analysis

This repository contains my completed Module Two assignment for *CS 255: System Analysis and Design*.  
The purpose of this assignment is to analyze and document the **functional requirements**, **nonfunctional requirements**, **assumptions**, and **limitations** for a Learning Management System (LMS) designed for YOUser University.

---

## 📌 Assignment Overview
Module Two focuses on identifying the essential system requirements that define how the LMS should function and what constraints or expectations shape its design. These requirements are supported by research from credible industry sources and formatted in APA style.

---

## 📂 Contents of This Submission

### **1. Functional Requirements**
This section outlines the core capabilities the LMS must provide, including:
- User authentication and role-based access  
- Course creation and content management  
- Enrollment and user management  
- Assignments, assessments, and gradebook functionality  
- Communication and collaboration tools  
- Data backup and recovery  

Each requirement includes:
- A clear description  
- A rationale explaining its importance  
- A supporting APA‑formatted source  

---

### **2. Nonfunctional Requirements**
This section defines the system qualities that ensure performance and reliability, such as:
- Usability and intuitive interface  
- High availability and reliability  
- Scalability  
- Performance and responsiveness  
- Security and data protection  
- Maintainability and supportability  

Each requirement is supported with rationale and APA citations.

---

### **3. Assumptions**
Assumptions clarify expectations not explicitly stated by the client, including:
- Users have reliable internet access and modern browsers  
- The LMS will integrate with an existing or planned Student Information System (SIS)  

---

### **4. Limitations**
This section identifies constraints that may impact system design, such as:
- Budget limitations restricting advanced features  
- Timeline constraints limiting custom development  

---
