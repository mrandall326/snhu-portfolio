## 📌 Part 1 — Linked List Implementation (LinkedList.cpp)

This assignment required building a **singly linked list** from scratch in C++, including:

- Manual pointer management  
- Node creation and deletion  
- Append and prepend operations  
- Searching for a bid by ID  
- Removing nodes safely  
- Traversing and printing the list  

The program loads bid data from a CSV file and stores each record in the linked list, allowing the user to interact with the data through a menu‑driven interface.

### **What I Learned**
- How linked lists operate at a low level  
- How to manage head, tail, and size correctly  
- How to avoid pointer‑related bugs and broken links  
- How to handle edge cases (empty list, removing head/tail, invalid IDs)  
- Why careful memory management is essential in dynamic structures
