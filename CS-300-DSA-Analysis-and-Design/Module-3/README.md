# CS 300 – Module 3  
### Singly Linked List Implementation & Code Reflection

This module contains my work for **Module 3: Linked Lists** in *CS 300: Data Structures and Algorithms*.  
The focus of this assignment was to implement a **singly linked list** from scratch in C++, including all pointer management, node manipulation, and list operations without relying on built‑in containers.

---

## 📌 Assignment Overview
The program loads bid data from a CSV file and stores each record in a manually implemented linked list.  
The list supports:

- **Append** – add a bid to the end  
- **Prepend** – add a bid to the front  
- **Search** – locate a bid by ID  
- **Remove** – delete a bid by ID  
- **PrintList** – traverse and display all bids  

This module reinforces understanding of dynamic memory, pointer manipulation, and the internal mechanics of linked data structures.

---

## 🧠 What I Learned
Through this module, I strengthened my ability to:

- Implement a linked list using raw pointers  
- Manage head, tail, and size safely  
- Handle edge cases such as empty lists, removing the head, and removing the tail  
- Debug pointer‑related issues and avoid broken links  
- Write clean, modular functions that follow the single‑responsibility principle  
- Test list operations with both valid and invalid inputs  

This assignment provided hands‑on experience with how linked lists operate “under the hood,” beyond what high‑level containers abstract away.
