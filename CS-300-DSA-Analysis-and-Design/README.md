# CS 300 – Data Structures and Algorithms  
### Analysis • Design • Implementation

This repository contains my work for **CS 300: Data Structures and Algorithms** at Southern New Hampshire University.  
The course focuses on algorithmic thinking, performance analysis, and the design and implementation of core data structures. Each module folder contains the assignments, pseudocode, analysis, and documentation completed throughout the term.

## 📌 Course Overview
CS 300 emphasizes:

- Big‑O analysis and algorithm efficiency  
- Evaluating time and space complexity

- Translating pseudocode into working code  
- Understanding trade‑offs between structure, performance, and scalability  
- Communicating design decisions through clear documentation  

The work in this repository reflects these core skills.
