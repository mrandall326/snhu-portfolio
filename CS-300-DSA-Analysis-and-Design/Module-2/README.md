# CS 300 – Module 2  
### Vector Sorting Program & Code Reflection

This module contains my work for **Module 2: Vector Sorting** in *CS 300: Data Structures and Algorithms*.  
The focus of this assignment was to implement two sorting algorithms—**selection sort** and **quicksort**—and compare their behavior, performance, and algorithmic complexity when applied to a vector of municipal auction bids loaded from a CSV file.

---

## 📌 Assignment Overview
The program loads bid data into a vector and allows the user to sort the results using:

- **Selection Sort**  
  A simple, quadratic‑time algorithm that repeatedly selects the smallest remaining element.

- **Quicksort**  
  A more efficient divide‑and‑conquer algorithm using a Hoare‑style partition scheme.

The assignment reinforces understanding of algorithmic complexity, vector operations in C++, and the trade‑offs between different sorting techniques.
