### Project One: Full Pseudocode Document & Runtime Analysis

This module contains the complete submission for **Project One** in *CS 300: Data Structures and Algorithms*.

## 📌 Project One Overview

The goal of Project One is to design the data structures and logic for a course advising program.  
The final submission includes:

- A **fully completed pseudocode document** containing:
  - **Milestone 1:** Vector Data Structure  
  - **Milestone 2:** Hash Table Data Structure  
  - **Milestone 3:** Binary Search Tree Data Structure  
  - Shared program menu logic  
  - Updated pseudocode for printing all courses in sorted order  
- A **runtime analysis paper** comparing the performance of all three structures  
- A discussion of trade‑offs, advantages, and disadvantages of each approach  

This project demonstrates the ability to design, analyze, and compare multiple data structures for the same problem.
