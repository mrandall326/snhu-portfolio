## 🧩 Final Project Requirements (Summary)

### **1. Input Handling**
- Prompt the user for the course data file name  
- Load and parse the file into course objects  
- Store all courses in the BST  

### **2. Menu System**
The program must include:

- **Option 1:** Load course data  
- **Option 2:** Print all courses in alphanumeric order  
- **Option 3:** Print course information (title + prerequisites)  
- **Option 9:** Exit  

### **3. Data Structure Implementation**
Use the **Binary Search Tree**, as recommended in Project One, to support:

- Efficient search  
- Sorted output via inorder traversal  
- Fast insertion  

### **4. Course List Output**
- Sort courses alphanumerically  
- Print all course numbers and titles  
- Include all CS and math courses  

### **5. Course Information Lookup**
- Prompt user for a course number  
- Print the course title  
- Print all prerequisite course numbers and titles  

### **6. Best Practices**
- Clear variable names  
- Inline comments  
- Error handling for invalid input  
- No external libraries or CSV parsers  
- All code contained in a single `.cpp` file
